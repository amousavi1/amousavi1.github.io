2.1 Sequential Models and RNNs

DATA 443/643 · Week 2 · PDF · Slides

A hidden state that reads the sequence one token at a time, with shared weights.

These notes match the lecture slides. Use (slides) on the course hub for the deck.

An MLP sees a vector and forgets. Language is a sequence: the meaning of not depends on what came before. A recurrent net keeps a state and updates it at every token.

This week is the historical path to transformers. You still need it: LSTMs show up in speech and time series, and the failure mode (a chain of Jacobians) is why Week 3 exists.

1. The cell

At step t the cell takes

  • the new token embedding xt, and
  • the previous hidden state ht−1.

It emits ht, which is supposed to hold both. That vector is the memory.

The same weights are used at every step. That is weight sharing along time, the sequence analogue of a CNN’s shared filter.

Between two independent sequences (two reviews in a batch) you reset h0=0. The loop lives inside one sequence.

If you do not reset, review 2 starts with leftover sentiment from review 1. That is leakage, not transfer learning.

2. Unrolled in time

Write the loop as a chain. Three tokens, one set of weights:

ht=tanh(Whht−1+Wxxt+b).

A CNN looks at a fixed neighborhood, in parallel. An RNN looks at everything so far, in order, and cannot fully parallelize across time. That is the accuracy / speed tradeoff.

Unrolling is how you backprop. The picture is one graph with copies of Wh,Wx. There are not three different matrices named Wh(1),Wh(2),Wh(3).

3. What the state has to carry

If the first word is the subject of a verb twenty tokens later, ht must still contain that subject. The cell is a lossy compressor: every step overwrites. Week 2.2 is what happens to the gradient on that long path. Week 2.3 adds gates so the cell can choose what to keep.

A many-to-one RNN (sentiment) uses the last hT. A many-to-many RNN (tagging, language modeling) emits at every t. Next-token LM: predict xt+1 from ht.

4. Teaching this note

30–40 minutes. Draw the cell, unroll three tokens with shared Wh, then do the 2-D numeric example with h0=0. Play 0:00–12:00 of StatQuest RNNs (the loop and the unroll). Save vanishing gradients for note 2.2 even if the video teases them.

5. Worked example

Let d=2, b=0, h0=0,

Wh=[0.5000.5],Wx=I,x1=[10],x2=[01].

Step 1: Whh0+Wxx1=x1, so h1=tanh(x1)≈[0.760] because tanh(1)≈0.76.

Step 2: Whh1+Wxx2≈[0.381], then h2=tanh(·)≈[0.360.76].

The same Wh was used twice. Token 1 still has a shrunk footprint in h2 (0.76→0.36). That shrinkage is the teaser for vanishing gradients.

6. Where students get stuck

  • Drawing a new Wh at each time step (no sharing).
  • Feeding the whole sentence as one concatenated vector “to make it an MLP.”
  • Forgetting to reset h between batch items.

7. Video

Watch StatQuest: Recurrent Neural Networks, Clearly Explained.

Pause on the first unroll (same weights copied) and on the moment the hidden state is described as memory. Skip any long software demo; the board math is the point.

8. Practice

  1. Unroll three tokens on paper with d=2, h0=0. Which matrices are reused?

  2. Why reset the state between two unrelated documents in a batch?

  3. Name one thing an RNN can mix that a kernel of size 5 cannot, in a single layer.

  4. Using the worked example’s Wh,Wx and x3=[11], write the pre-activation Whh2+Wxx3 with h2≈[0.360.76]. Do not bother with tanh if you are short on time; the linear mix is the lesson.

  5. If every Wh were replaced by 0.1I, and xt=0 after t=1, approximately how does ‖ht‖ scale with t? (Geometric sequence.)
