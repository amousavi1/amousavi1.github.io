\vspace{1em}

Write a function named \texttt{column\_check} in an R script. It takes a data frame \texttt{df} with exactly two columns.
Returns \texttt{FALSE} if either of the columns is not numeric (\texttt{is.numeric}). If both columns are numeric, it
computes their maximum values and returns 1 if the maximum of the first column is greater than or equal
to the maximum of the second column. Otherwise, it returns \texttt{Second Column}.
