Dplyr Practice: 10 Exercises with Solutions

DATA 412/612 · Week 5 · Source (.qmd)

Setup

We will use the flights dataset from the nycflights13 package.

library(dplyr)
library(nycflights13)

Question 1: Unique Destinations by Origin

Using distinct(), group_by(), and summarise(), find the number of unique destination airports served by each origin airport (JFK, LGA, and EWR).

Your output should contain exactly three rows and two columns: origin and n_destinations.

Solution

flights %>%
  distinct(origin, dest) %>%
  group_by(origin) %>%
  summarise(
    n_destinations = n(),
    .groups = "drop"
  )
## # A tibble: 3 × 2
##   origin n_destinations
##   <chr>           <int>
## 1 EWR                86
## 2 JFK                70
## 3 LGA                68

Explanation: distinct(origin, dest) keeps unique origin-destination pairs. After grouping by origin, n() counts the number of destinations for each airport.

Question 2: Airport Names and Departure Status

Using mutate() and case_when(), create two new columns:

  • origin_name: “John F. Kennedy” for JFK, “LaGuardia” for LGA, and “Newark Liberty” for EWR.
  • delay_status: “Early” for negative departure delays, “On time” for zero, “Delayed” for positive, and NA for missing delays.

Display only origin, origin_name, dep_delay, and delay_status.

Solution

flights %>%
  mutate(
    origin_name = case_when(
      origin == "JFK" ~ "John F. Kennedy",
      origin == "LGA" ~ "LaGuardia",
      origin == "EWR" ~ "Newark Liberty",
      TRUE ~ NA_character_
    ),
    delay_status = case_when(
      is.na(dep_delay) ~ NA_character_,
      dep_delay < 0 ~ "Early",
      dep_delay == 0 ~ "On time",
      dep_delay > 0 ~ "Delayed"
    )
  ) %>%
  select(origin, origin_name, dep_delay, delay_status)

Question 3: Filtering and Sorting Flights

Find flights satisfying all the following conditions:

  • Departed from JFK or LGA.
  • Flew to LAX, SFO, or MIA.
  • Had a departure delay greater than 30 minutes.
  • Took place in July or August.

Display month, day, origin, dest, carrier, and dep_delay, sorted by departure delay from highest to lowest.

Solution

flights %>%
  filter(
    origin %in% c("JFK", "LGA"),
    dest %in% c("LAX", "SFO", "MIA"),
    dep_delay > 30,
    month %in% c(7, 8)
  ) %>%
  select(month, day, origin, dest, carrier, dep_delay) %>%
  arrange(desc(dep_delay))

Question 4: Airline Performance Summary

For each airline (carrier), calculate:

  1. Total number of flights.
  2. Number of distinct destinations served.
  3. Average departure delay, excluding missing values.
  4. Percentage of flights departing more than 15 minutes late, excluding missing departure delays from the denominator.

Sort by average departure delay from highest to lowest.

Solution

flights %>%
  group_by(carrier) %>%
  summarise(
    n_flights = n(),
    n_destinations = n_distinct(dest),
    avg_dep_delay = mean(dep_delay, na.rm = TRUE),
    pct_late = 100 * mean(dep_delay > 15, na.rm = TRUE),

Question 5: Arrival Delay Categories

Create a column called arrival_category using case_when():

Arrival delay Category
Less than 0 Early
Exactly 0 On time
1–30 minutes Minor delay
31–60 minutes Moderate delay
More than 60 minutes Severe delay
Missing Unknown

Then count the number of flights in each category, sorted from most frequent to least frequent.

Solution

flights %>%
  mutate(
    arrival_category = case_when(
      is.na(arr_delay) ~ "Unknown",
      arr_delay < 0 ~ "Early",
      arr_delay == 0 ~ "On time",
      arr_delay <= 30 ~ "Minor delay",
      arr_delay <= 60 ~ "Moderate delay",
      TRUE ~ "Severe delay"
    )
  ) %>%
  count(arrival_category, sort = TRUE)
## # A tibble: 6 × 2
##   arrival_category      n
##   <chr>             <int>
## 1 Early            188933
## 2 Minor delay       81505
## 3 Severe delay      27789
## 4 Moderate delay    23710
## 5 Unknown            9430
## 6 On time            5409

Explanation: Conditions in case_when() are checked from top to bottom. Because earlier conditions already exclude delays of 30 minutes or less, arr_delay <= 60 correctly identifies moderate delays.

Question 6: Destinations Served by Multiple Airlines

Find destinations served by at least three different airlines.

For each qualifying destination, display:

  • Destination airport.
  • Number of distinct airlines.
  • Total number of flights.
  • Average arrival delay, excluding missing values.

Only include destinations with at least 500 flights. Sort by average arrival delay from highest to lowest.

Solution

flights %>%

Question 7: Using across() for Multiple Statistics

For each origin airport, calculate the mean and median of:

  • dep_delay
  • arr_delay
  • air_time

Use a single across() statement with a list of functions. Ignore missing values.

Solution

flights %>%
  group_by(origin) %>%
  summarise(
    across(
      c(dep_delay, arr_delay, air_time),
      .fns = list(
        mean = ~ mean(.x, na.rm = TRUE),
        median = ~ median(.x, na.rm = TRUE)
      ),
      .names = "{.col}_{.fn}"
    ),
    .groups = "drop"
  )
## # A tibble: 3 × 7
##   origin dep_delay_mean dep_delay_median arr_delay_mean arr_delay_median
##   <chr>           <dbl>            <dbl>          <dbl>            <dbl>
## 1 EWR              15.1               -1           9.11               -4
## 2 JFK              12.1               -1           5.55               -6
## 3 LGA              10.3               -3           5.78               -5
## # ℹ 2 more variables: air_time_mean <dbl>, air_time_median <dbl>

Explanation: across() applies multiple functions to multiple columns. The .names argument determines the names of the output columns.

Question 8: Performance Relative to Airline Average

For each airline, create:

  • carrier_avg_delay: the airline’s average departure delay, excluding missing values.
  • relative_status:
    • “Better than average” if a flight’s delay is below its airline’s average.
    • “Worse than average” if above.
    • “Exactly average” if equal.
    • NA if the flight delay or airline average is missing.

Display carrier, dep_delay, carrier_avg_delay, and relative_status.

Solution

flights %>%
  group_by(carrier) %>%
  mutate(
    carrier_avg_delay = mean(dep_delay, na.rm = TRUE),
    relative_status = case_when(
      is.na(dep_delay) | is.na(carrier_avg_delay) ~ NA_character_,
      dep_delay < carrier_avg_delay ~ "Better than average",
      dep_delay > carrier_avg_delay ~ "Worse than average",
      TRUE ~ "Exactly average"
    )
  ) %>%
  ungroup() %>%
  select(carrier, dep_delay, carrier_avg_delay, relative_status)

Question 9: Three Worst Days for Each Airline

Find the three worst days for each airline based on average arrival delay.

Define a day using year, month, and day.

Only consider airline-day combinations with at least 10 flights having nonmissing arrival delays.

Return carrier, year, month, day, n_flights, and avg_arr_delay.

Use slice_max() and return no more than three rows per airline.

Solution

flights %>%
  filter(!is.na(arr_delay)) %>%
  group_by(carrier, year, month, day) %>%
  summarise(
    n_flights = n(),
    avg_arr_delay = mean(arr_delay),
    .groups = "drop"
  ) %>%
  filter(n_flights >= 10) %>%
  group_by(carrier) %>%
  slice_max(
    order_by = avg_arr_delay,
    n = 3,
    with_ties = FALSE
  ) %>%
  ungroup() %>%
  arrange(carrier, desc(avg_arr_delay)) %>%
  select(carrier, year, month, day, n_flights, avg_arr_delay)

Question 10: Comprehensive Destination Analysis

Among destinations with at least 1,000 scheduled flights, identify the five destinations with the worst departure-delay performance.

For each destination, calculate:

  1. n_flights: total scheduled flights.
  2. n_delayed: flights with dep_delay > 0.
  3. pct_delayed: percentage of flights delayed, excluding missing departure delays from the denominator.
  4. avg_delay: average departure delay among delayed flights only.
  5. n_carriers: number of distinct airlines serving the destination.

Rank by pct_delayed (highest first), breaking ties by avg_delay (highest first), then destination code alphabetically.

Return exactly five destinations.

Solution

flights %>%
  group_by(dest) %>%
  summarise(
    n_flights = n(),
    n_delayed = sum(dep_delay > 0, na.rm = TRUE),
    pct_delayed = 100 * mean(dep_delay > 0, na.rm = TRUE),
    avg_delay = mean(dep_delay[dep_delay > 0 & !is.na(dep_delay)]),
    n_carriers = n_distinct(carrier),
    .groups = "drop"
  ) %>%
  filter(n_flights >= 1000) %>%
  arrange(
    desc(pct_delayed),
    desc(avg_delay),
    dest
  ) %>%
  slice_head(n = 5)
## # A tibble: 5 × 6
##   dest  n_flights n_delayed pct_delayed avg_delay n_carriers
##   <chr>     <int>     <int>       <dbl>     <dbl>      <int>
## 1 MDW        4113      2251        55.7      35.5          1
## 2 PDX        1354       681        50.5      35.4          3
## 3 DEN        7266      3624        50.3      33.7          5
## 4 MHT        1009       458        49.1      47.8          2
## 5 MKE        2802      1312        48.3      43.1          4

Explanation: We calculate statistics for each destination. The percentage excludes missing departure delays. The average delay includes only flights that actually departed late. Finally, we filter, sort, and select the five worst destinations.
