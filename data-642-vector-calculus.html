1.4 Basic Vector Calculus

DATA 442/642 · Week 1 · PDF

Gradients, Jacobians, and Hessians in the notation this course uses.

1. Gradient

J(θ):ℝl→ℝ. Vary one coordinate, hold the others. Those partials, stacked, are the gradient. This course writes it as a row

∇J=[∂J∂θ1∂J∂θ2⋯∂J∂θl]∈ℝ1×l.

Some books write a column. Be consistent inside one derivation. Descent updates look like θ←θ−α(∇J)⊤ if ∇J is a row.

2. Chain rule

If J=J(θ1(t),θ2(t)), then

dJdt=∂J∂θ1dθ1dt+∂J∂θ2dθ2dt.

That is a gradient times a Jacobian. Back-propagation (Module 6) is this rule applied to a long composition. You do not need the neural-net story yet. You do need to be willing to write the product.

3. Hessian

If J is twice differentiable,

∇2J=[∂2J/∂θ12∂2J/∂θ1∂θ2∂2J/∂θ2∂θ1∂2J/∂θ22].

The mixed partials match (Schwarz), so the Hessian is symmetric. It measures curvature.

At a critical point ∇J=0:

  • ∇2J positive definite ⇒ local minimum;
  • negative definite ⇒ local maximum;
  • indefinite ⇒ saddle.

Newton’s method (week 2) solves a linear system with this matrix every step. Eigenvalues of ∇2J are why a long thin valley makes steepest descent zigzag.
