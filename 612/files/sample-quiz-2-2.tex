Cumulative through October 28 (weeks 1--9). The new material is
tidyr, mutating and filtering joins, databases, and strings.

Write your answers in an R script. You may use R and RStudio.
You may \textbf{not} use the internet or your notes.
Load the tidyverse and \texttt{nycflights13}.

\begin{enumerate}
\item Compute both an inner join and a left join of \texttt{visits}
to \texttt{branches} by \texttt{branch}.
In one sentence each, say which rows of \texttt{visits} the inner
join drops and which columns the left join still contains for an
unmatched branch.

\begin{lstlisting}
branches <- tibble(
  branch = c("Shaw", "Rosslyn"),
  seats = c(80, 60)
)
visits <- tibble(
  patron = c("Ari", "Bea", "Cal"),
  branch = c("Shaw", "Petworth", "Rosslyn")
)
\end{lstlisting}

\item From \texttt{flights}, keep only the January rows, and from
those keep the distinct \texttt{carrier} values.
Then use a filtering join so that \texttt{airlines} contains only
carriers that flew in January.
How many airlines remain?

\item From each string below, extract the five-digit ZIP code when
the string is two letters, a comma, one space, and then five digits.
Otherwise the result for that string should be missing.

\begin{lstlisting}
c("MD 21228", "WA, 76731", "VA: 34124", "FL, 21225", "ca, 45691")
\end{lstlisting}

\item Split \texttt{code} into \texttt{carrier} and \texttt{flight}.
\texttt{flight} should be an integer.

\begin{lstlisting}
codes <- tibble(code = c("AA-101", "DL-303", "UA-22"))
\end{lstlisting}

\item Reshape \texttt{wide} to one row per carrier and month, with a
numeric \texttt{month} and a \texttt{delays} column. Drop missing
delay counts.

\begin{lstlisting}
wide <- tibble(
  carrier = c("AA", "DL"),
  m1 = c(4, NA),
  m2 = c(1, 3)
)
\end{lstlisting}
\end{enumerate}
