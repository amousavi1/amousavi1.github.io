\vspace{0.3em}

Cumulative through September 23 (weeks 1--4): R and the tidyverse,
pipes and functions, ggplot2, and dplyr rows, columns, and groups.

Write your answers in an R script. You may use R and RStudio.
You may \textbf{not} use the internet or your notes.
Load the tidyverse. \texttt{mpg} is in \texttt{ggplot2}.

\begin{enumerate}
\item Write a function \texttt{geomean} that takes one numeric vector.
Drop every \texttt{NA} and every value that is not strictly positive.
Using a pipe, return the geometric mean of what remains
(\texttt{exp} of the mean of the logs).
If nothing remains, return \texttt{NA}.
Try it on \texttt{c(1, 4, NA, -2, 0)} and on \texttt{c(NA, -1)}.

\item Using \texttt{mpg}, make a scatter plot of engine size
(\texttt{displ}) against highway mileage (\texttt{hwy}).
Color the points by drive (\texttt{drv}) and facet by \texttt{year}.
Add a title and use \texttt{theme\_bw()}.

\item From \texttt{mpg}, keep cars with 4 or 6 cylinders whose highway
mileage is at least 25. Sort by highway mileage, highest first.
Return only \texttt{manufacturer}, \texttt{model}, \texttt{cyl}, and
\texttt{hwy}.

\item For each \texttt{class} in \texttt{mpg}, report how many cars are
in that class and the median highway mileage.
Sort by that median, highest first.
\end{enumerate}
