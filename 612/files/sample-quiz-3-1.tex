\vspace{0.25em}

Cumulative through December 2 (weeks 1--13). The new material is
R Markdown presentations, chunk options, tables, and citations.

Write your answers in an R script or a short \texttt{.Rmd}.
You may use R and RStudio.
You may \textbf{not} use the internet or your notes.
You do not have to knit. Write the YAML, the chunk headers, and the
code you would put in the file.

\begin{enumerate}
\item Write a minimal YAML header for an ioslides presentation titled
\texttt{Delay notes}, with you as the author.
Under it, write the markdown for two slides after the title slide.
Each slide has a title and one sentence.
Say which heading level starts a slide in ioslides.

\item You need three chunks:
\begin{itemize}
  \item a setup chunk that loads the tidyverse and is not printed;
  \item a chunk that shows both the code and a \texttt{knitr::kable()}
        table of \texttt{mpg} summarized to the median \texttt{hwy}
        by \texttt{class}, with the caption \texttt{Median highway
        mileage};
  \item a plot chunk whose code is hidden, whose messages are hidden,
        and whose figure still appears.
\end{itemize}
Write the chunk options for each. Set the shared defaults in the
setup chunk with \texttt{knitr::opts\_chunk\$set()}, and override
them only where a chunk differs.

\item Point the document at a bibliography file \texttt{refs.bib}.
In the body, cite the key \texttt{wickham2017r4ds} in parentheses,
and end the file with a \texttt{References} heading so the entry
is printed.

\item Still in that document, add a chunk with \texttt{echo = TRUE}
that runs a two-sample \texttt{t.test()} of \texttt{hwy} for
\texttt{drv} \texttt{"f"} against \texttt{drv} \texttt{"r"} in
\texttt{mpg}. State the null hypothesis in one sentence under the chunk.
\end{enumerate}
