Weeks 1--10. The new material is stringr, factors, and lubridate.

Write your answers in an R script. You may use R and RStudio.
You may use your notes and the course website
(\texttt{https://amousavi1.github.io/612/data-612.html}).
You may not use Google, any other website, or an LLM.
Load the tidyverse.

\begin{enumerate}
\item On the character vector below, return only the digits that
follow a lowercase \texttt{room} and a space. Use one \texttt{stringr}
call. Every other string should be \texttt{NA}.

\begin{lstlisting}
c("room 214", "lab", "room 8", "Room 30", "hall 12")
\end{lstlisting}

\item In \texttt{labs}, reorder \texttt{dept} by the mean of
\texttt{score}, highest mean first. Report the levels.
Do not use \texttt{arrange()}.

\begin{lstlisting}
labs <- tibble(
  dept = c("Math", "Math", "CS", "CS", "Physics", "Physics"),
  score = c(80, 100, 120, 140, 90, 110)
)
\end{lstlisting}

\item Let \texttt{dt} be

\begin{lstlisting}
ymd_hms("2026-11-11 14:30:00", tz = "UTC")
\end{lstlisting}

Show \texttt{with\_tz(dt, "America/New\_York")} and
\texttt{force\_tz(dt, "America/New\_York")}.
In one sentence, say which call changes the instant and which
call only changes the clock.

\item From \texttt{visits}, parse \texttt{when} with \texttt{ymd()}.
Put \texttt{note} in lower case and keep the rows whose note starts
with \texttt{gate}. On the rows that remain, order \texttt{site}
by frequency, most common first, and report the levels.

\begin{lstlisting}
visits <- tibble(
  when = c("2026-11-01", "2026-11-11", "2026-11-03", "2026-12-02"),
  site = c("north", "south", "north", "east"),
  note = c("gate A", "GATE b", "gate a", "hall C")
)
\end{lstlisting}
\end{enumerate}
