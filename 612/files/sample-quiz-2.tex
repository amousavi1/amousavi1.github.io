Weeks 1--4: R and the tidyverse, pipes and functions, ggplot2,
and dplyr rows, columns, and groups.

Write your answers in an R script. You may use R and RStudio.
You may use your notes and the course website
(\texttt{https://amousavi1.github.io/612/data-612.html}).
You may not use Google, any other website, or an LLM.
Load the tidyverse. \texttt{mpg} is in \texttt{ggplot2}.

\begin{enumerate}
\item Build this data frame and, with tidyverse verbs, report the type
of each column and how many \texttt{NA}s each column contains.

\begin{lstlisting}
scores <- tibble(
  name  = c("Ada", "Lin", "Grace", "Alan"),
  lab   = c("8", "10", "NA", "7"),
  score = c(9.5, NA, 8, 10)
)
\end{lstlisting}

\item Write a function \texttt{late\_flag} that takes \textbf{one} number.
Return \texttt{"on time"} when the number is less than or equal to 0,
\texttt{"late"} when it is greater than 0 and at most 30,
\texttt{"very late"} when it is greater than 30,
and \texttt{NA} when the input is \texttt{NA}.
Try it on \texttt{-5}, \texttt{10}, \texttt{45}, and \texttt{NA}.

\item Using \texttt{mpg}, keep only the classes \texttt{compact} and
\texttt{midsize}. Make a boxplot of highway mileage (\texttt{hwy})
by drive (\texttt{drv}). Label the axes in words and use
\texttt{theme\_bw()}.

\item Add a column \texttt{total} equal to \texttt{cty + hwy}.
For each manufacturer, report the number of cars and the mean of
\texttt{total}. Keep only manufacturers with at least 5 cars, and
sort by that mean, highest first.
\end{enumerate}
