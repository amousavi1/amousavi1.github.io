Write your answers in an R script. You may use R and RStudio.
You may \textbf{not} use the internet or your notes.

\begin{enumerate}
\item Write a function named \texttt{column\_check} in an R script. It takes a
data frame \texttt{df} with exactly two columns.
\begin{itemize}
  \item Return \texttt{FALSE} if either column is not numeric
        (\texttt{is.numeric}).
  \item If both columns are numeric, compute their maximum values and return
        \texttt{1} if the maximum of the first column is greater than or equal
        to the maximum of the second column.
  \item Otherwise, return \texttt{Second Column}.
\end{itemize}
\end{enumerate}
