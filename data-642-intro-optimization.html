2.1 Introduction to Optimization

DATA 442/642 · Week 2 · PDF

Cost functions, local versus global minima, convexity, and first- and second-order tests.

1. The problem

Pick a set S (usually ℝl) and a cost J:S→ℝ. Solve

J(θ^)=minθ∈SJ(θ).

Maximizing profit P is minimizing −P. This course always writes a min.

Linear regression is the first example. Model y=θ⊤𝐱+ε. Average squared error

J(θ)=12m∑i=1m(θ⊤𝐱(i)−y(i))2.

Each gradient step is “make the residuals smaller.”

2. Local versus global

A local minimum is lowest in a neighborhood. A global minimum is lowest on all of S.

On a mountain trail, a valley is local. Sea level in the whole range is global.

If J is convex,

J(tθ+(1−t)β)≤tJ(θ)+(1−t)J(β),

every local min is global. That is the property that makes Module 1 feel safe.

Convex costs (this course) Not convex
Linear regression (MSE) Deep nets
Logistic regression (log loss) k-means
Soft-margin SVM GMM likelihood

3. First- and second-order tests

First-order (necessary). At a local min of a smooth unconstrained J, ∇J(θ^)=0. The slope is flat.

Second-order (sufficient). If also ∇2J(θ^) is positive definite, you have a local min.

A zero gradient is not enough: a saddle is flat and is not a min. The Hessian tells the two cases apart. Week 2’s algorithms either follow −∇J or invert ∇2J.
